# ApexPlanet Cybersecurity and Ethical Hacking Internship – Task 5

## Capstone Project & Incident Response Simulation

### Project Title
DVWA Web Application Penetration Testing and Incident Response Simulation

## Project Overview
This capstone project demonstrates practical cybersecurity and ethical hacking skills through security testing of Damn Vulnerable Web Application (DVWA) in a controlled local laboratory environment.

The project covers reconnaissance, service scanning, vulnerability identification, controlled exploitation, evidence collection, vulnerability mitigation, and incident response simulation.

## Objectives
- Perform reconnaissance and security assessment of DVWA.
- Identify and demonstrate web application vulnerabilities.
- Collect security testing evidence.
- Analyze Apache web server logs.
- Simulate incident detection and response.
- Apply containment and recovery procedures.
- Document findings and recommended mitigations.

## Scope
### In Scope
- DVWA running on a local Kali Linux environment.
- Apache web server.
- Controlled security testing.
- SQL Injection testing.
- Apache access-log analysis.
- Incident response simulation.

### Out of Scope
- Public websites.
- Unauthorized systems.
- Real-world credential theft.
- Destructive attacks.

## Tools Used
- Kali Linux
- DVWA
- Apache
- Nmap
- cURL
- iptables
- Linux command-line tools

## Incident Response
The project includes a controlled incident-response simulation covering:

1. Detection
2. Analysis
3. Containment
4. Eradication
5. Recovery
6. Lessons Learned

## Key Findings
- SQL Injection vulnerability in the intentionally vulnerable DVWA application.
- Weak security configuration in the test environment.
- Suspicious requests can be detected through Apache access logs.
- Firewall rules can be used as a temporary containment mechanism.

## Mitigation
Recommended controls include:
- Prepared statements and parameterized queries.
- Strong input validation.
- Secure application configuration.
- Proper logging and monitoring.
- Firewall access controls.
- Regular vulnerability assessments.

## Ethical Statement
All security testing was performed in an authorized, isolated laboratory environment for educational and cybersecurity training purposes.
