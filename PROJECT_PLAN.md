# ApexPlanet Task 5 – Capstone Project Planning

## Project Title
DVWA Web Application Penetration Testing and Incident Response Simulation

## 1. Objectives

The main objectives of this capstone project are:

- To perform security testing on the DVWA web application in a controlled lab environment.
- To conduct reconnaissance and service scanning.
- To identify and demonstrate a controlled web application vulnerability.
- To collect and document security evidence using screenshots and log files.
- To understand how an attack can be detected through web server logs.
- To simulate incident response activities including detection, analysis, containment, eradication, and recovery.
- To recommend suitable security mitigation strategies.
- To prepare professional cybersecurity documentation.

## 2. Scope

The project is performed only in an authorized local virtual laboratory environment.

### In Scope
- DVWA web application running on Kali Linux.
- Local Apache web server.
- Nmap reconnaissance and service identification.
- HTTP header analysis.
- Controlled SQL Injection testing.
- Apache access log analysis.
- Firewall-based incident containment.
- Incident recovery verification.

### Out of Scope
- Attacking real-world websites or systems.
- Accessing unauthorized accounts or data.
- Disrupting external services.
- Deploying real malware.
- Collecting real user credentials.

## 3. Tools Used

- Kali Linux
- DVWA
- Apache2
- Nmap
- cURL
- Apache Access Logs
